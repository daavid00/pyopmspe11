pyopmspe11.utils.writefile module#

Write OPM grid, property, deck, and saturation-function files.

The module serializes COORD and ZCORN geometry, compact keyword arrays, boundary pore-volume edits, rendered DATA files, and generated saturation tables for the selected SPE11 configuration.
